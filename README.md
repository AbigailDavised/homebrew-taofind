# homebrew-taofind

Official isolated Homebrew Tap for **taofind.com**.

## Installation

```bash
brew tap AbigailDavised/taofind
brew install taofind-cli
```

## Quick Start

```bash
taofind-cli --help
```

## Capabilities & Architecture
- Direct terminal client connecting to official MCP streamable HTTP endpoint: `https://taofind.com/api/mcp`
- Zero sign-in, zero tracking, stateless calculations
- Website: https://taofind.com
